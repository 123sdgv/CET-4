# 背单词

真题词汇背诵网页。iPhone Safari 优先，可添加到主屏幕离线使用。记忆曲线用 [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) v6（FSRS-7）。

## 上传新词

把 CSV 放进 `vocab/<语言代码>/`，提交到 `main` 分支，GitHub Actions 会自动校验、合并、部署。

- 英语：`vocab/en/`
- 以后加别的语言就新建文件夹：`vocab/ja/` 日语、`vocab/ko/` 韩语、`vocab/fr/` 法语、`vocab/de/` 德语、`vocab/es/` 西班牙语

文件名随意，例如 `CET4-2025-12-S2-B-xxx.csv`。

### CSV 规则（可以直接发给 ChatGPT）

- UTF-8 编码（带不带 BOM 都可以），第一行表头必须是：
  `id,type,front,meaning_zh,pos,usage,source_context,example_en,example_zh,priority,origin,source_id`
- `type`：`单词` 或 `短语`；`priority`：`核心` 或 `拓展`
- `front`、`meaning_zh` 不能为空；含逗号的字段用英文双引号包住，字段里的双引号写成两个 `""`
- `id`：`w_`（单词）或 `p_`（短语）+ SHA-1(front 去首尾空格、转小写、连续空格合成一个) 的前 12 位十六进制。**只对 front 做哈希，不加 type。** 也可以留空，构建时自动生成
- `source_context` 只放真题原文；`example_en` / `example_zh` 放补充例句

### 合并规则

- 同一个词（同一个 id）在多个文件里出现：释义、用法、例句以后上传的为准；真题原句和来源全部保留；任一文件标了核心就算核心
- 重复上传同一个 CSV 不会多出卡片，已有的学习进度和到期时间不受影响
- 从 CSV 删掉的词不再出现，进度保留，加回来就恢复
- 有坏行时构建失败并指出文件和行号，网站保持上一版词库

## 学习规则

- 每天先背完所有到期的旧词，再学「每日新词」设定数量的新词（在「我的」里改，5～100）。两样都背完算当天完成
- 不认识：隔 3 张再出现，直到点「认识」；眼熟：隔 6 张再出现一次
- 每次点击都记录并交给 FSRS 计算下次时间
- 凌晨 4 点换天
- 顽固词：最近 30 天点了 ≥3 次「不认识」。复习时按更高的记忆目标排期，所以出现更频繁。「我的 → 顽固词」里只翻看，不记录
- 已掌握：下次复习间隔 ≥21 天

## 数据

学习记录只保存在这台设备的浏览器里（IndexedDB），不会上传到 GitHub，也不会在设备之间自动同步。换设备用「我的 → 导出备份 / 从备份恢复」。

注意：iPhone 上 Safari 和「添加到主屏幕」的图标是两份独立的存储，请固定用其中一个（推荐主屏幕图标）。清除 Safari 网站数据会清掉记录，请定期导出备份（超过 7 天没备份时「导出备份」旁会有小红点）。

## 第一次部署

1. 仓库 Settings → Pages → Build and deployment → Source 选 **GitHub Actions**
2. 推送到 `main`（或在 Actions 页手动运行「构建并部署」）
3. 网址：`https://<用户名>.github.io/<仓库名>/`

## iPhone 添加到主屏幕

用 Safari 打开网址 → 底部分享按钮 → 「添加到主屏幕」→ 添加。之后从桌面图标打开，断网也能复习已缓存的词。

## Windows 本地运行

1. 安装 [Node.js 24](https://nodejs.org/)（ts-fsrs v6 要求 Node ≥ 24）
2. 在项目文件夹打开终端：
   ```
   npm install
   npm run dev      # 本地预览，按提示打开 http://localhost:5173
   npm test         # 运行测试
   npm run build    # 构建到 dist/
   ```

## 验收清单

自动测试（`npm test`）覆盖：CSV 解析与坏行行号、100 张真题词卡 ID、重复 CSV 不重建卡片、后上传为准、凌晨 4 点换天、过关规则、每日计划、连续 3 次评分后重新计算仍保留、缺席日期统计留白、跨日连续天数、顽固词、灰柱预测、备份日期往返、ts-fsrs 评分间隔。

手工检查：

1. 打开网站默认是单词页；点喇叭能读出英文；翻面看到中文、用法、真题原句
2. 评 3 张卡后刷新，计数和进度不变
3. 断网（飞行模式）从主屏幕图标打开，仍能继续背
4. 导出备份 → 清除网站数据 → 从备份恢复，统计和进度回来
5. 上传一个含新词的 CSV，部署完成后打开网站，新词出现，旧词的统计和到期时间不变
